# apps

Twee kleine webapps die volledig in de browser draaien. Bestanden blijven op het eigen apparaat; er wordt niets geüpload.

- `papierwerk/` — Papierwerk PDF: pdf's lezen, bewerken, ondertekenen, scannen, vergelijken en verkleinen.
- `omzetter/` — Omzetter: bestanden omzetten naar een ander formaat.

Beide zijn te installeren als app (PWA) en werken daarna ook zonder internet. Na een wijziging het versienummer in `sw.js` van de betreffende app ophogen, anders blijven geïnstalleerde apps de oude versie tonen.
